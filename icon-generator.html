SharingPortal · Generatore icone

Apri questo file nel browser, clicca i bottoni e scarica le icone. Nessuna installazione richiesta.

Anteprima

Download

Istruzioni

1
Clicca Scarica tutte le icone. Il browser potrebbe chiederti di confermare più download: accetta.
2
Sposta i file scaricati nella cartella principale del repository SharingPortal (stessa posizione di index.html).
3
Aggiungi il file site.webmanifest (te lo fornisco sotto) nella stessa cartella.
4
Aggiorna index.html con le righe fornite per collegare favicon, Apple icon e manifest.
5
Commit e push su GitHub. Attendi 1-2 minuti che GitHub Pages aggiorni la cache.
Nota: Safari su macOS potrebbe rinominare favicon.ico in favicon-ico. Se succede, rinominalo manualmente in favicon.ico.
